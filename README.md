# FV_Bounce

Проект: подбор параметров торговых стратегий на основе уровней + ATR.

## 📁 Содержание

### Старые файлы (Bounce стратегия - pivot-based)
- `bounce_atr_opt_colab.ipynb`, `bounce_only.ipynb`, `breakout_only.ipynb` — Jupyter ноутбуки с бэктестами
- `FV_Bounce.mq5` — MT5 советник (Pivot/Camarilla/DeMark уровни)
- `FV_Bounce.ex5` — скомпилированный файл советника

### 🛠️ Инструменты экспорта (новое)
- **`export_rates.mq5`** — скрипт MT5 для экспорта исторических данных
  - Автоматически определяет таймфрейм по графику прикрепления
  - Сохраняет в CSV формат готовый для ноутбука
  - Параметры: дата начала, дата конца, символ
  - Подробная инструкция: [EXPORT_DATA_GUIDE.md](EXPORT_DATA_GUIDE.md)

### ✨ НОВОЕ: Level Reversal EA — Отскок от уровней с подтверждением паттерном

#### 1. **Бэктест и оптимизация (Python)**
   - **Файл:** `level_reversal_opt.ipynb`
   - **Что делает:**
     - Загрузка исторических данных M5/M15/H4/D1 EURUSD
     - Реализация компонентов стратегии: определение уровней (swing high/low), тренд-фильтр (EMA+ADX), паттерны (пин-бар, поглощение, доджи)
     - Бэктест на backtesting.py с расчётом метрик (Return, Sharpe, Max Drawdown, Win Rate, Profit Factor)
     - Walk-forward анализ для проверки на переобучение
     - Оптимизация параметров
   - **Как использовать:**
     1. Загрузить в `content/` файлы EURUSD по M5, M15, H4, D1 (CSV формат с колонками Open, High, Low, Close, Volume)
     2. Открыть ноутбук в Jupyter
     3. Выполнить ячейки последовательно для загрузки данных и запуска бэктеста
     4. Включить оптимизацию (раскомментировать) для поиска лучших параметров
     5. Экспортировать найденные параметры для переноса в MQL5

#### 2. **MT5 Советник**
   - **Файл:** `level_reversal_ea.mq5`
   - **Логика:**
     - **Старший ТФ (H4):** поиск сильных горизонтальных уровней (swing high/low), определение тренда (EMA50/EMA200 + ADX)
     - **Младший ТФ (M5/M15):** вход по разворотным паттернам (пин-бар, поглощение, доджи)
     - **Риск-менеджмент:** SL = ATR × множитель, TP = SL × коэффициент R:R (1:2, 1:3, настраиваемо)
     - **Позиции:** максимум 1 открытая одновременно, лот до 0.1 на паре EURUSD
     - **Визуализация:** уровни отрисовываются на графике (зелёные = поддержка, красные = сопротивление)
   - **Параметры входа (input):**
     - `InpEntryTF` — таймфрейм входа (M5 или M15)
     - `InpMinTouches` — минимум касаний для сильного уровня (2–4)
     - `InpSlAtrMult` — множитель ATR для SL
     - `InpRR` — соотношение TP/SL (1:2 = 2.0, 1:3 = 3.0)
     - Фильтры паттернов: `InpUsePinBar`, `InpUseEngulfing`, `InpUseDoji`
   - **Установка в MT5:**
     1. Скопировать `level_reversal_ea.mq5` в папку `MQL5/Experts` вашего терминала MT5
     2. Перекомпилировать в редакторе MQL5 (F7)
     3. Перетащить компилированный советник на график EURUSD (рекомендуемые ТФ: M5, M15, H4)
     4. Установить параметры согласно результатам оптимизации из ноутбука
     5. Закрепить советник на демо-счёте для тестирования перед использованием на реальном счёте

## 📊 Рабочий процесс

1. **Подготовка данных:** загрузить CSV файлы M5/M15/H4/D1 в папку `content/`
2. **Бэктест (Python):** запустить `level_reversal_opt.ipynb` для анализа и поиска оптимальных параметров
3. **Форвард-тест (MT5):** перенести параметры в `level_reversal_ea.mq5`, скомпилировать и протестировать на демо
4. **Запуск на реальном счёте:** после положительных результатов на демо

---

## ⚠️ Риски

- **Это торговая стратегия** — результаты бэктеста не гарантируют будущую прибыль; возможны убытки вплоть до полной потери депозита
- **Мал депозит ($700):** высокая относительная волатильность просадки; требуется консервативный управление риском
- **Свечные паттерны** на коротких ТФ (M5/M15) дают много ложных сигналов; обязателен walk-forward тест
