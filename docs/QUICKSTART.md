# Быстрый старт: Level Reversal EA

## Шаг 1: Подготовка данных (КРИТИЧНО)

Загрузите в папку `content/` файлы истории EURUSD. Есть два способа:

### 🔧 **Способ 1: Автоматический экспорт (РЕКОМЕНДУЕТСЯ)**

Используйте скрипт `export_rates.mq5`:

1. **Скопировать скрипт в MT5:**
   ```bash
   cp export_rates.mq5 /path/to/MetaTrader5/MQL5/Scripts/
   ```

2. **Открыть график EURUSD** на нужном таймфрейме (например, M5)

3. **Прикрепить скрипт:**
   - Вид → Навигатор → Scripts → `export_rates`
   - Перетащить на график
   - Установить параметры:
     - InpStartYear = 2020, InpStartMonth = 1, InpStartDay = 1
     - InpEndYear = 2025, InpEndMonth = 12, InpEndDay = 31
     - InpSymbol = EURUSD
   - Нажать OK

4. **Результат:**
   - Файл сохранится в папку `Files` терминала (путь будет в Журнале)
   - Скопировать файл в `/workspaces/FV_Bounce/content/`

5. **Повторить для других таймфреймов:** M5, M15, H4, D1
   - Просто откройте график каждого ТФ и повторите шаги 2-4

**Подробнее:** [EXPORT_DATA_GUIDE.md](EXPORT_DATA_GUIDE.md)

---

### 📊 **Способ 2: Ручной экспорт**

Если скрипт не подходит, экспортируйте данные вручную:

1. Открыть MT5 → Окно → Обозреватель данных
2. Разверните EURUSD → выберите таймфрейм (M5, M15, H4, D1)
3. Кликните правой кнопкой → Экспортировать
4. Сохраните как CSV файл в папку `content/`

**Формат CSV:** 
```
Time,Open,High,Low,Close,Volume
2020-01-01 00:00:00,1.1234,1.1250,1.1230,1.1240,1000
...
```

**Результат:** После экспорта (любым способом) в папке `content/` должны быть:
- `EURUSD_M5_*.csv` — 5-минутные бары
- `EURUSD_M15_*.csv` — 15-минутные бары  
- `EURUSD_H4_*.csv` — 4-часовые бары (или создадутся из M5)
- `EURUSD_D1_*.csv` — дневные бары (или создадутся из M5)

## Шаг 2: Бэктест и оптимизация (Python)

### 2.1 Открыть Jupyter notebook

```bash
cd /workspaces/FV_Bounce
jupyter notebook level_reversal_opt.ipynb
```

### 2.2 Запустить ячейки последовательно:

1. **Загрузка данных** — убедитесь, что CSV файлы прочитались корректно
2. **Функции обработки** — компоненты стратегии (ATR, уровни, тренд, паттерны)
3. **Класс стратегии** — LevelReversalStrategy для backtesting.py
4. **Бэктест** — базовый запуск на M5 данных
5. **Walk-Forward** — проверка на переобучение (разделение train/test)
6. **Оптимизация** — раскомментировать и запустить `bt.optimize()` для поиска лучших параметров

### 2.3 Интерпретация результатов:

Смотрите метрики:
- **Return [%]** — общая прибыль (% на начальный депозит $700)
- **Sharpe Ratio** — качество прибыли (выше = лучше, >1.0 хорошо)
- **Max Drawdown [%]** — максимальное падение (старайтесь < 30%)
- **Profit Factor** — (прибыль / убыток), желательно > 1.5
- **Win Rate [%]** — % прибыльных сделок (> 40% неплохо)
- **# Trades** — количество сделок (минимум 20–30 для статистики)

**Если результаты плохие:**
- Попробуйте другой младший ТФ (M15 вместо M5)
- Увеличьте `min_touches` (3–4) для более строгого фильтра уровней
- Отключите малоэффективные паттерны (например, `use_doji = False`)

### 2.4 Экспорт параметров для MQL5:

После оптимизации скопируйте найденные **оптимальные параметры** (последняя ячейка ноутбука):
```
InpSlAtrMult = 2.0
InpRR = 2.0
InpMinTouches = 3
InpLevelBufferATR = 1.0
InpEntryTF = M15  (или M5)
...
```

```mql5

input double InpRR = 2.0;              // Ваше оптимальное R:R

// ... и т.д.
```

Нажать **F7** или кликнуть "Компилировать" → файл `level_reversal_ea.ex5` создан

## Шаг 4: Тест на демо-счёте (Strategy Tester)

### 4.1 Открыть Strategy Tester

MT5 → Вид → Стратегический тестер (или Ctrl+R)

### 4.2 Настроить параметры тестера:

- **Советник:** `level_reversal_ea`
- **Символ:** EURUSD
- **Таймфрейм:** M5 или M15 (в зависимости от `InpEntryTF`)
- **Период:** 2024-01-01 — 2025-12-31 (тестовый период, не использовавшийся при оптимизации!)
- **Начальный депозит:** 700 USD
- **Комиссия:** 0.0002 (0.02% на сторону)
- **Спред:** авто (или задайте фиксированный 2 пункта для EURUSD)

### 4.3 Запустить тест

- "Быстрая оптимизация" (если нужно) или просто "Старт"
- Дождаться результатов (обычно 5–30 минут)

### 4.4 Оценить результаты

Смотрите отчет с теми же метриками, что и Python бэктест.  
**Допустимое расхождение** между Python и MT5 результатами: ±5–10% (из-за спреда, проскальзывания, округления).

**Если результаты на тесте сильно отличаются от оптимизации:**
- Возможно переобучение параметров
- Попробуйте другой период оптимизации или более консервативные параметры

## 🔧 Типичные проблемы и решения

### Проблема: "No data" при загрузке CSV в ноутбук
**Решение:**
- Проверьте путь к файлу в `content/`
- Убедитесь, что имя файла содержит M5, M15, H4 или D1 (например, `EURUSD_M5_2020-2025.csv`)
- Проверьте формат CSV: должны быть колонки `Open, High, Low, Close, Volume` или `<OPEN>, <HIGH>, <LOW>, <CLOSE>, <TICK_VOLUME>`

### Проблема: "Результаты бэктеста намного хуже, чем оптимизация"
**Решение:**
- Это переобучение параметров к одному периоду
- Используйте walk-forward анализ (разделение train/test 70/30)
- Попробуйте расширить диапазон оптимизации (более консервативные параметры)
- Увеличьте `min_touches` или уменьшите `entry_zone_atr` для более строгого фильтра

### Проблема: Советник в MT5 не даёт сигналов
**Решение:**
- Проверьте, что советник имеет статус "Запущен" (вкладка справа вверху)
- Убедитесь, что на графике видны уровни (зелёные/красные линии) - это означает, что уровни считаются
- Проверьте параметр `InpMinTouches` - может быть слишком высоким, нужно снизить до 2–3
- Посмотрите логи: Вид → Журнал → выберите вкладку "Эксперты" (может быть ошибка инициализации)

### Проблема: Много сделок, но большая часть в убыток
**Решение:**
- Отключите неработающие паттерны (например, `InpUseDoji = false`)
- Увеличьте `InpSlAtrMult` для более широкого SL
- Уменьшите `InpRR` для более скромного профита (1:2 вместо 1:3)
- Попробуйте другой младший ТФ (M15 обычно более стабилен, чем M5)
